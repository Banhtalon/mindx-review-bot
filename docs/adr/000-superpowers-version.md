# ADR 000 — Superpowers version for the repository

- Date: 2026-08-10
- Status: Accepted
- Source: Codex local skill catalog
- Version: `openai-curated-remote/superpowers` `6.2.0`

## Decision

Use the locally available Superpowers workflow for repository changes:
brainstorming, writing plans, isolated branch/worktree handling, TDD,
systematic debugging, code review and verification before completion.

This records the development protocol only. It does not add a runtime
dependency to the application.
